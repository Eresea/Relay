# Palette's Journal

## 2026-09-20 - Copy confirmation feedback in high-security interfaces

**Learning:** Copy buttons in password managers need transient visual and screen-reader feedback ('check' icon + ARIA label change to 'Copied!') so users don't repeatedly click or feel uncertain whether a sensitive string was successfully written to the clipboard.
**Action:** Always provide brief (1.5-2s) success feedback and updated accessible labels on clipboard copy actions.
