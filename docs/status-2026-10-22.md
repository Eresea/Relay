# Relay status — 22 October 2026

Relay has substantial functionality, but unfinished reliability and daily-use work should come before broader features. The immediate priorities are quiet startup, vault safety, resilient background work, and a useful overlay.

Local `main` and `origin/main` references are stale; apparent unmerged fixes are already merged remotely. No checkout or branch changes were made.
- No open pull requests. Three open GitHub issues: #25, #26, #27.
- Latest published release: [v0.2.1](https://github.com/Eresea/Relay/releases/tag/v0.2.1), 27 September. Windows/Linux installers, Android APK/AAB, updater signatures and `latest.json` exist. It predates the October fixes. Source versions still say `0.2.1`, so a newer release number is needed to deliver these changes through version-based updates.
- Latest [main CI](https://github.com/Eresea/Relay/actions/runs/37517171829) passed on 6 October. This is historical CI evidence, not a live integration check.

## Recommended sequence

1. The login Run entry now points at the installed GUI build; verify at next login. Verify #25 on Windows CI before closing it.
2. #26 and #27 are implemented and tested locally; verify packaged Windows behavior before closing issues. Gmail `invalid_grant` is now actionable in Settings; verify with the affected account.
3. Review the current overlay changes in the packaged desktop app and adjust from concurrent-job, failure, focus and scaling behavior.
4. Complete Nexus/GitHub/Linear/Codex end-to-end checks. Fix observed failures in bounded changes.
5. Verify vault sync on two devices, including wrong-password and concurrent-revision conflict cases.
6. Run desktop/Android upgrade checks, update misleading documentation and publish a version above `0.2.1` once validated.
7. Choose the first new feature. The smallest continuation already planned is one source-backed Runtime metric. Remote execution, public status hosting and a general orchestration framework need separate scope decisions.

Do not publish a release or change live accounts until their own validation is complete.
